# 内置音效

`thumb-piano/` 是岛屿内置的 Cindy 通知音效（「拇指琴」），2026-11-06 为 fly-island 用代码合成：圆润的基音、一个很快消失的金属泛音，加一点回声，24 kHz 单声道 WAV。旋律和音色都是原创的，不来自任何其他软件或素材库，随本项目以 MIT 协议发布。

| 文件 | 事件 |
|---|---|
| `complete.wav` | 任务完成、定时与后台任务结束 |
| `error.wav` | 出错 |
| `question.wav` | 需要你回答 |

会话开始、上下文中断、额度提醒等旧版的事件音效已随 Agent 页去掉。
