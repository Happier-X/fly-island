# Cindy 通知

全局方向见 [DESIGN.md](../../DESIGN.md)。数据来源与判定规则见 [docs/cindy-notifications.md](../cindy-notifications.md)。

## 收起的岛

- AI Agent 区（状态灯、会话标题、会话数、Agent 页、上下文占用、按会话的预览）已整块删除，岛上只留通知。
- 原来的「运行中会话数」位置改成**通知角标**，跟随「外观 → 收起的岛」的排列，和邮件、置物架、音乐图标同一套尺寸：有未处理通知时显示铃铛和数量，超过 99 显示 `99+`。（用户确认：小角标/数字，不新造大 UI）
- 点角标把 Cindy 的窗口拿到前台，不打开岛上的面板。没找到 Cindy 的窗口时角标保留。
- 没有未处理通知时不占位置；「Cindy 通知」模块关闭时这里仍是原来的灰色收起圆点。
- 提示音只区分完成 / 提问 / 出错三种音效，一次只响最重要的一条；Cindy 已在前台或游戏模式勿扰时不响。

## 设置

- 侧栏不再有「AI Agent」分组，两个页面合并成「功能 → Cindy 通知」一页：
  - 总开关（关闭后不读库、不显示角标）；
  - 四类事件各一个开关：任务完成、需要你回答、定时与后台任务、出错；
  - 「响提示音」一个开关，沿用原来的音效设置键；
  - 「数据来源」：能不能读、数据库路径、最近读取时间与读到的条数、失败原因，外加「重新读取」。
- 原本只服务 Agent 页的选项（显示方式、排序、分组、归档动画、卡片光效、时间范围、提醒停留时间、再次提醒、弹窗开关）全部去掉。
- 外观页的岛屿预览同步改成：收起的岛显示待办文字与通知角标，展开的岛画待办页，不再画 Agent 会话。

## 与旧版本的差别

v3.3.0 及以前，岛上还有 AI Agent 状态灯、会话标题、Agent 页和弹出提醒，更早的 v3.1.0 及以前还装过 Codex / Claude Code 的钩子。现在这些都没有了：

- 没有岛上审批：Cindy 的授权卡在它自己的界面里，没有可拦截的接口。
- 没有会话列表与上下文占用：通知只关心「有没有事要你处理」。
- 没有跳终端 / 编辑器：点通知就是把 Cindy 拿到前面。
