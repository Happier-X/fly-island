# 截图：图标与界面规范

全局方向见 [DESIGN.md](../../DESIGN.md)，岛屿视觉规范见 [island.md](island.md)。截图覆盖层、长截图状态条和 OCR 气泡是原生窗口，不经过 React，但沿用同一套图标与描边。

## 图标

- 来源：与岛上相同的 **Lucide**（项目已安装的 `lucide-react`）。原生端不手写、不另引图标库，也不使用 PixPin 的商标或素材。
- 导出的 SVG 在 `crates/airsnip/assets/icons/lucide/`，由 `scripts/sync-screenshot-icons.mjs` 生成；新增或替换图标只改脚本里的对照表，不手改 SVG。
- 描边：Lucide 的 24 单位网格、圆端点、圆连接；在 26px 按钮里按 16px 绘制（显示描边约 1.5px），和岛上 16px 图标的视觉重量一致。
- 不再按「墨水包围盒」逐个放大：短横线、圆点这类窄图标会因此变成粗杠，也会让相邻图标描边粗细不一。图标固定在原网格上居中。
- 状态色沿用主题调色板：默认 `icon`，禁用 `icon_dim`，激活强调色 `accent`，悬停底色 `row_hover` / `accent_soft`。只有数据与状态用颜色，其余黑白灰。

## 悬停与激活

- 工具栏按钮悬停先出现底色反馈，约 0.4 秒后弹文字提示（原有行为）。
- 选中的工具 / 色块用强调底色，图标换成 `icon` 或强调色；不可用的动作（撤销、重做、填充）置灰但仍占位。
- OCR 气泡的图钉点亮表示置顶，关闭按钮悬停只给底色，不变色。

## 可访问性

- 每个按钮都有可见的文字提示（覆盖层的悬浮提示、长截图状态条的说明行），不靠图标单独表达含义。
- 新增图标必须能在 16px 下辨认；`render::icon` 的墨水率测试守着上下限。

## 贴图与 OCR 操作

- 贴图窗口：滚轮 10%（Alt 1%）、中键恢复原大小、`T` 置顶、`L` 锁定、空格进入标注、`Ctrl+C` / `Ctrl+S` 复制与保存。锁定后用右键菜单解锁。
- OCR 气泡沿用岛上的卡片语言：图钉与关闭常驻、文本区 1px 边框、底部「复制」与「自动复制」。
