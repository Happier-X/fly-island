# AI Agent：会话标题与 Agent 页

全局方向见 [DESIGN.md](../../DESIGN.md)。数据来源见 [docs/agent-status.md](../agent-status.md)。

## AI Agent 会话标题

- Cindy 里的会话跑起来时，小岛在待办位置显示「Cindy 图标 + 会话标题」，标题单行省略、不撑宽小岛；完成后保留 3 秒再恢复待办，失败或可能中断时继续显示。优先级：消息预览 > Agent 标题 > 待办。多个会话同时运行时只显示最近有动静的一个。（用户确认：图标和标题）
- 标题优先用 Cindy 记录的会话标题，没有时退回文件夹名。「AI Agent → 小岛显示」中可关闭，默认开启。
- 图标用 Cindy 自己的应用图标（16px 圆角 4px），与 QQ / 微信图标同尺寸。
- 小岛显示 Agent 标题时，点击（或悬停展开）打开岛上的 Agent 页，不直接跳 Cindy。
- AI Agent 开启时，小岛最右侧的灰色收起圆点换成正在运行的会话数（蓝色数字），点击打开 Agent 页；没有运行中的会话时不显示。AI Agent 关闭时保留原灰点。（用户确认）

## Agent 页

- 列出最近 2 小时有动静的 Cindy 会话，正在运行和等你回答的排前面。数据直接读 Cindy 的本地数据库，不装钩子、不改 Cindy 的任何设置。
- 每行：Cindy 图标、"项目名 · 标题"、模型、权限模式标记、状态灯与会话环同色（红"等待确认"或失败、绿运行、暗绿 10 分钟无动静、灰完成；没看过的完成会话灰点发亮，判断见 `sessionLight.ts`）、最近一条消息（最多两行）、状态与多久前更新。项目名取会话的工作目录。
- 显示方式（`agentSessionView`）：列表（默认）、卡片、紧凑。卡片每个会话一张 62px、按状态灯颜色描边的卡片，右端是上下文 tokens；紧凑每个会话一行 34px。归档、看过与没看过、找不到窗口的提示三种方式一样。卡片光效（`agentCardEffects`，默认关）与归档动画（`agentArchiveMotion`，默认滑出）照旧。
- "等待确认"：Cindy 里 `ask_user`（问你）或 `plan_review`（等你确认计划）的消息还没有回答时显示。等待中的会话计入小岛上的会话数，也继续显示它的标题。
- 点击一行把 Cindy 的窗口切到前台：所有会话都在 Cindy 一个窗口里，最小化的先恢复。Cindy 没开或找不到窗口时在该行提示"没找到 Cindy 的窗口"。
- 对齐与归档（B17，用户确认 2026-11-07）：圆点和每行最右的图标都对齐到岛屿 20px 的内边距；每行在 Cindy 图标右边有一个一直显示的归档图标，点后这一行先滑出再收起，左下角浮出「已归档 · 撤销」小胶囊。
- 入口：展开后左上角的状态灯图标、小岛上的会话数、显示 Agent 标题时点击小岛。AI Agent 关闭时没有 Agent 页。
- 弹出提醒：会话开始、完成、出错或停下等你回答时，收起的岛屿（含贴边隐藏）自动展开到 Agent 页，只显示触发的那一个会话（完成或出错时显示它最后一条消息，最多 3 行），停留 5 秒（3–30 秒可选）后收起；鼠标停在岛上时不收起，在面板里点过就不再自动收起。Cindy 已在前台、游戏模式勿扰、或你正在用展开的岛屿时不弹。"弹出提醒"里会话开始可选每一轮开始 / 只在新会话开始 / 不弹（默认不弹），其余三种事件各有开关，默认都开。
- 没处理时再提醒（B6.4.1）：停在问你回答的会话过了设定时间还在等，就再弹一次并再响一次提问音效；每次等待只补一次，回答后再次等待会重新计时。默认不再提醒。
- 提示音只留完成、出错、问你要回答；一轮结束后要保持完成 6 秒才响，同一轮只响一次，Cindy 自己接着跑的后续几轮不再响。

## 与旧版本（Codex / Claude Code 钩子）的差别

v3.1.0 及以前，岛上显示的是 Codex 和 Claude Code 的会话：装钩子、读它们的会话记录、按终端或编辑器窗口定位、在岛上审批和回答问题。现在这些都删掉了，原因和替代方案见 [docs/agent-status.md](../agent-status.md)：

- 没有岛上审批：Cindy 的授权卡在它自己的界面里，没有可拦截的接口。
- 没有"等你回复"和"做完了"的区分靠回复末尾的符号标记：Cindy 直接告诉我们哪条消息在等你回答。
- 没有跳终端 / 编辑器：点会话就是把 Cindy 拿到前面。
- 没有额度环：Cindy 不提供用量上限数据，卡片上显示的是每个会话的上下文大小。
