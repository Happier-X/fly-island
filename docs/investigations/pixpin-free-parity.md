# 截图工作流与 PixPin 免费功能对照

查询日期：2026-11-13。基线：FocuSD Island v3.2.1 + vendored AirSnip。

本文以官方手册为依据，不采用第三方评测的免费功能表，也不以试用等同永久免费。状态来自源码核对，GUI 验证另记。此任务禁止提交、推送、发布或覆盖安装。

## 图标实施（已完成）

- 来源：项目已安装 `lucide-react`，由 `scripts/sync-screenshot-icons.mjs` 导出到 `crates/airsnip/assets/icons/lucide/`（ISC，`THIRD-PARTY.md` 已登记），不引入 PixPin 素材。
- 覆盖：覆盖层 25 个工具/编辑/输出图标、长截图状态条（撤销/保存/OCR/贴图/完成/取消）、OCR 气泡（图钉/关闭）、设置面板行内按钮。设置窗口入口沿用同一个 Lucide `Scan`。
- 描边与尺寸：保留 24 单位原始坐标，26px 按钮里按 16px 绘制，显示描边约 1.5px，与岛上 16px 图标一致；**不再按单个图标包围盒放大**，窄图标（直线、加减号）不再变成粗杠，相邻图标描边一致。
- 渲染：加载时把描边展开成填充轮廓（圆端点/圆连接），绘制仍是原来的纯填充路径；墨水率测试范围按线框图标收紧。
- 文字提示：图标的可读含义仍由原有悬浮提示、状态条说明文字和右键菜单文字承担；没有只靠图标表达的按钮。
- 规范记录在 `docs/design/screenshot.md`，图标对照表在 `crates/airsnip/assets/icons/lucide/README.md`。

## 本轮实现与验证

实现：
- 图标统一到 Lucide（见上）。
- 贴图：滚轮 10% / Alt 1%、中键复位、T 置顶、L 锁定（含禁用拖动/缩放/编辑与右键解锁）、Ctrl+C、Ctrl+S。
- 截图：Ctrl+A 当前屏 / 全屏；Alt 像素辅助与颜色/坐标复制；Ctrl+Shift+S 快速保存；设置项「截图后自动保存」（默认关）。
- 长截图：状态条增加 OCR 与贴图出口，二者完成后只处理结果本身，不再顺手复制保存。
- 设置界面新增自动保存开关（中英文案），`screenshot.json` 旧文件缺字段时回退关闭。

验证证据：
- `cargo test --manifest-path crates/airsnip/Cargo.toml`：383 通过，0 失败，15 ignored（含此前基线可疑的 `session_rejects_zero_size` 本次通过）。
- `cargo test --manifest-path src-tauri/Cargo.toml`：194 通过，0 失败。
- `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets`：无告警。单独对 `crates/airsnip` 跑 `--all-targets` 会列出 vendored crate 的既有告警，本次新增文件未出现在其中。
- `pnpm tauri build --no-bundle`：成功生成 `src-tauri/target/release/focusd-island.exe`。
- 覆盖层实跑（临时托管示例）：真实 D3D 抓屏成功（含 HDR 色调映射），覆盖层建窗+首帧 139.6ms，日志确认已上屏；示例进程未声明 Per-Monitor V2 时抓屏报 0x887A0004，与本文档记录的 DPI 前提一致。
- 未能完成的 GUI 输入验证：覆盖层 `SetForegroundWindow` 被系统前台锁拒绝，输入法/修饰键状态无法由注入方式模拟（PostMessage 不设置 `GetKeyState`），因此 Ctrl+A、Alt 取色、贴图 T/L 的**真实按键链路未在本机验证**；Release 构建与单元测试通过不等于交互已验证。桌面截图工具在同一次实跑中未拍到覆盖层，原因未定，记录为环境限制而不是「界面正常」的证据。
