## 更新内容

这是 [flyl1u/fly-island](https://github.com/flyl1u/fly-island) v3.0.3 的分支版本，主要新增了截图能力。

- **截图**：按 `Ctrl+Shift+A`（可改）唤起全屏覆盖层，框选后可以裁剪、标注、复制或另存；双屏、混合 DPI、HDR 显示器下位置都准确。
- **十种标注**：矩形、箭头、文本、荧光笔、模糊、聚光灯、序号、直线、椭圆、手绘，可以拖动、缩放、撤销和重做。
- **长截图**：滚动页面自动拼接，适合聊天记录和长文章。
- **OCR**：框选后直接识别文字，语种跟随系统或指定已安装的语言包。
- **贴图**：把截图钉在屏幕上，可以缩放，也可以再编辑。
- **设置页新增「截图」分区**：全局快捷键、保存格式（PNG / JPEG / WebP）、默认保存目录、5 个标注色、覆盖层内的工具快捷键（可逐个改绑）、工具栏每一项的显隐、OCR 识别语言、覆盖层界面缩放。
- **许可证改为 GPL-3.0-only**：截图来自 [AirSnip（轻截）](https://github.com/bd-dxg/airsnip) 的移植代码，同样以 GPL-3.0-only 发布，因此整个项目随之改为 GPL-3.0。v3.0.3 及更早版本的 MIT 声明保留在 [NOTICE](https://github.com/Happier-X/fly-island/blob/main/NOTICE)。
- **应用内更新改为指向本仓库**：更新检查使用本仓库自己的签名密钥，装过上游版本的不会被拉回原版。

待办、笔记、归档、剪贴板、翻译、音乐、消息提醒等功能与 v3.0.3 保持一致。

## What's new

This is a fork of [flyl1u/fly-island](https://github.com/flyl1u/fly-island) v3.0.3 whose main addition is screenshot capture.

- **Screenshots**: press `Ctrl+Shift+A` (configurable) for a full-screen overlay, then crop, annotate, copy or save. Placement stays correct across multiple monitors, mixed DPI and HDR displays.
- **Ten annotations**: rectangle, arrow, text, highlighter, blur, spotlight, number, line, ellipse and freehand, each draggable and resizable, with undo and redo.
- **Scrolling capture**: scroll a page and the frames are stitched together, for chat logs and long articles.
- **OCR**: recognise the text in a selection, in the system language or a chosen installed language pack.
- **Pinned images**: pin a screenshot on screen, zoom it, and edit it again later.
- **A new Screenshot section in Settings**: global shortcut, save format (PNG / JPEG / WebP), default folder, the five annotation colours, the overlay's own tool keys (rebindable one by one), which toolbar items are shown, the OCR language and the overlay scale.
- **Relicensed to GPL-3.0-only**: the screenshot code is ported from [AirSnip](https://github.com/bd-dxg/airsnip), itself GPL-3.0-only, so the whole project follows. The MIT notice for v3.0.3 and earlier is kept in [NOTICE](https://github.com/Happier-X/fly-island/blob/main/NOTICE).
- **In-app updates now point at this repository**: updates are verified with this repository's own signing key, so an install will not be pulled back to the upstream build.

Todos, notes, archives, clipboard, translation, music and notifications are unchanged from v3.0.3.
