## 更新内容

贴图（钉在屏幕上的截图）现在可以直接框选取字。

- **贴图右键「识别文字…」**：点它后光标变成十字，在贴图上拖出矩形，松手就用本地 OCR 识别这一块，结果出现在原来的识别气泡里；点「复制」即可把文字粘到别处，「自动复制」开着时会直接写进剪贴板。
- **Alt + 拖拽**：不想开菜单时，按住 Alt 直接在贴图上拖也能框选取字，走同一套逻辑。
- **缩放过的贴图也能识别**：框选范围会换算回原图像素并钳在贴图边界内，所以缩小或放大显示时识别的是它显示的那块文字，不会错位。
- **取消**：Esc、右键、点到别的窗口都会退出框选，不留痕迹；框选面积为 0 时不会触发识别。

其余功能（待办、笔记、归档、剪贴板、翻译、音乐、消息提醒、截图本身、AI Agent 状态）与 v3.2.0 保持一致。

## What's new

A pinned screenshot can now have its text picked out with a drag.

- **Right-click a pin → Recognize text...**: the cursor turns into a crosshair, drag a rectangle over the pin and the local OCR engine reads that part of the image. The result opens in the usual OCR bubble; click Copy to paste the text elsewhere, or leave Auto-copy on to put it on the clipboard right away.
- **Alt + drag**: hold Alt and drag on a pin to make a selection without opening the menu; it is the same code path.
- **Zoomed pins work too**: the selection is mapped back to the image's own pixels and clamped to its bounds, so a pin shown smaller or larger still reads the text it displays, without drifting.
- **Cancelling**: Esc, right-clicking or clicking another window leaves select mode without a trace; a zero-area selection never triggers recognition.

Everything else (todos, notes, archive, clipboard, translation, music, notifications, screenshots themselves, AI Agent status) is unchanged from v3.2.0.
