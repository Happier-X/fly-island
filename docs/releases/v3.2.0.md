## 更新内容

这个版本把岛上的 AI Agent 区从「Codex + Claude Code」换成 **Cindy**。

- **AI 状态改为读 Cindy**：岛上的状态灯、会话列表、提示音和弹出，现在显示的是你在 Cindy 里跑的任务——哪个在跑、哪个在等你回答、哪个刚做完，点一行直接把 Cindy 拿到前台。
- **去掉 Codex / Claude Code 接入**：不再往它们的配置里写钩子，也不再扫它们的会话文件。升级后首次启动会一次性清掉旧版本写进 `~/.claude/settings.json` 和 `~/.codex/config.toml` 的条目（你自己手写的规则保留）。
- **岛上没有审批卡了**：Cindy 的授权提示在它自己的窗口里，没有可以拦截的接口，所以「在岛上允许 / 拒绝」这项能力取消了。审批请仍在 Cindy 里点。
- **设置页「AI Agent → 数据来源」**：显示 Cindy 数据库的路径、读到了几个会话、读取是否正常；以前那页的「安装 / 修复钩子」一并去掉。
- **会话卡片**：显示模型、上下文占用和最近一条消息；额度环换成上下文占用显示。

其余功能（待办、笔记、归档、剪贴板、翻译、音乐、消息提醒、截图）与 v3.1.0 保持一致。

## What's new

This release replaces the island's AI Agent section: it now shows **Cindy** instead of Codex and Claude Code.

- **Agent status comes from Cindy**: the status light, session list, sounds and pop-ups show what is running in Cindy — which task is working, which one waits for your answer, which just finished. Clicking a row brings Cindy to the front.
- **Codex and Claude Code are gone**: no hooks are written into their settings any more, and their session files are not scanned. The first start after upgrading removes the entries older builds wrote into `~/.claude/settings.json` and `~/.codex/config.toml`, keeping rules you wrote yourself.
- **No approval cards on the island**: Cindy asks for permission in its own window and offers no way to intercept it, so approving from the island is no longer possible. Approve in Cindy.
- **Settings → AI Agent → Data source**: shows the path of Cindy's database, how many sessions were read and whether reading works; the old install/repair hooks page is gone with it.
- **Session cards** show the model, context occupancy and the latest message; quota rings became context occupancy.

Todos, notes, archives, clipboard, translation, music, notifications and screenshots are unchanged from v3.1.0.
