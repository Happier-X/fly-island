## 更新内容

- **新增岛内「外设电量」页**：展开悬浮岛后，可从页面圆点打开，按设备类型显示已连接鼠标、键盘、耳机和无线接收器的名称与电量百分比，并提供手动刷新。
- 电量来自三路系统接口：蓝牙 LE GATT 电池服务、标准 HID Battery Strength，以及 Logitech HID++（2.4G 接收器）。只显示真正读到电量的设备；读不到、无权限或设备休眠时不显示，也不会弹出错误提示。
- 设置 → 功能 → 外设电量新增模块开关与刷新间隔（30 / 60 / 120 / 300 秒，默认 60 秒）。功能默认开启，且只在「外设电量」页展开时读取。
- 保持现有默认：不显示笔记本自身电池、手柄和触控笔；蓝牙经典 A2DP 耳机通常不提供 GATT 电量，系统读不到时不会出现在列表中。

### 验证范围

- 前端检查、浏览器回归（14 个回归页全部通过）、Rust 测试与 Windows 签名构建均通过；新增单测覆盖 HID 电量缩放、HID++ 回复解析、设备分类、去重排序和设置默认值。
- 真机读到 3 台蓝牙 LE 设备：MCHOSE G3 A（鼠标 20%）、keycool 5.0（键盘 1%）、MCHOSE X75 V2（键盘 100%）。
- **未真机验证 2.4G HID++ 路径**：测试时本机 Logitech LIGHTSPEED 接收器没有可响应的配对设备，只验证了解析单测和代码路径。
- **未真机验证标准 HID Battery Strength**：本机没有暴露该用途的真实设备。
- **蓝牙经典 A2DP 耳机通常不上报电量**，属于预期行为，不是读取失败。

## What's new

- **Added a Device battery page to the island.** Expand the island and open it from the page dots to see the name and battery percentage of connected mice, keyboards, headsets and wireless receivers, with a manual refresh button.
- Battery levels come from three system sources: Bluetooth LE GATT Battery Service, standard HID Battery Strength, and Logitech HID++ for 2.4 GHz receivers. Only devices whose level can actually be read are listed; unreadable, unauthorized or sleeping devices are left out without error dialogs.
- Settings → Features → Device battery has a module switch and a refresh interval (30 / 60 / 120 / 300 seconds, 60 by default). It is on by default and only reads while the Device battery page is expanded.
- Existing behavior is unchanged: the laptop's own battery, gamepads and styluses are excluded; Bluetooth Classic A2DP headsets usually do not expose a GATT battery level and are not listed when Windows cannot read one.

### Validation scope

- Frontend checks, browser regressions (all 14 pages passed), Rust tests and the signed Windows build passed. New unit tests cover HID level scaling, HID++ reply parsing, device classification, de-duplication and ordering, and the settings defaults.
- Three Bluetooth LE devices were read on the test machine: MCHOSE G3 A (mouse, 20%), keycool 5.0 (keyboard, 1%), and MCHOSE X75 V2 (keyboard, 100%).
- **The 2.4 GHz HID++ path was not verified on real hardware**: the Logitech LIGHTSPEED receiver had no responding paired device during testing, so only parsing tests and the code path were exercised.
- **Standard HID Battery Strength was not verified on real hardware**: no device exposing that usage was connected.
- **Bluetooth Classic A2DP headsets usually do not report a battery level**; that is expected rather than a read failure.
