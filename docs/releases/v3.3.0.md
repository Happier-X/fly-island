## 更新内容

本版补齐截图工具对标 PixPin 免费版的一批静态截图能力，并把原生截图界面换成与灵动岛一致的图标。会员专属能力（翻译、文档/表格/公式识别、智能擦除、PDF、长截图自动裁剪、配置同步等）与录屏不在本版范围内。

- **选区**：截图时按 Ctrl+A 选中鼠标所在显示器，再按一次选中全部屏幕。
- **像素辅助**：按住 Alt 在冻结画面上显示像素网格、屏幕坐标与颜色值；Alt+C 复制 HEX，Alt+Shift+C 复制 RGB，Alt+Ctrl+C 复制坐标。
- **贴图操作**：滚轮缩放 10%，Alt+滚轮 1%；中键恢复原始大小；T 置顶、L 锁定（锁定后不能拖动、缩放和编辑，右键菜单可解锁）；贴图内支持 Ctrl+C 复制、Ctrl+S 保存。
- **保存**：截图时 Ctrl+Shift+S 直接保存到设置的目录与格式，不弹对话框；设置 → 截图新增「截图后自动保存」（默认关闭），复制截图时同时写入一份文件，同名文件自动换名，不覆盖已有文件。
- **长截图结果**：状态条新增 OCR 与贴图按钮，拼接完成后可直接识别文字或把结果贴到屏幕。
- **图标**：截图工具栏、长截图状态条和 OCR 卡片的图标统一为项目在用的 Lucide 线条图标，尺寸与描边和灵动岛一致；不再按单个图标的墨迹范围放大，直线、加减号等窄图标不会变粗。

仍与 PixPin 免费版存在差距：按窗口/界面元素自动框选、尺寸与位置数值输入、比例锁定、中心缩放、贴图鼠标穿透/缩略图/隐藏恢复、文字/文件/颜色贴图、二维码识别、截图历史、打印、横向长截图、拼接后编辑与长截图自动滚动尚未实现。

## What's new

This release brings a set of static screenshot capabilities in line with PixPin's free tier, and replaces the native screenshot icons with the same Lucide set the island uses. Member-only features (translation, document/table/formula recognition, smart erase, PDF, long-shot auto crop, config sync) and screen recording are not part of this release.

- **Selection**: press Ctrl+A while capturing to select the monitor under the cursor; press again for the whole desktop.
- **Pixel helper**: hold Alt over the frozen image to see a pixel grid, screen coordinates and the color value. Alt+C copies HEX, Alt+Shift+C copies RGB, Alt+Ctrl+C copies the coordinates.
- **Pinned images**: wheel zooms 10% and Alt+wheel 1%; middle click restores the original size; T toggles always-on-top and L locks the pin (no drag, zoom or edit while locked; unlock from the right-click menu). Ctrl+C copies and Ctrl+S saves from the pin window.
- **Saving**: Ctrl+Shift+S saves straight to the configured folder and format without a dialog. Settings → Screenshots adds "Save after capture" (off by default), which also writes a file when you copy; existing files are never overwritten.
- **Long screenshots**: the status bar gains OCR and Pin buttons, so a finished stitch can be recognized or pinned directly.
- **Icons**: the capture toolbar, long-shot status bar and OCR card now use the project's Lucide line icons at the island's size and stroke. Icons are no longer scaled by their own ink bounds, so narrow glyphs such as line and plus/minus keep their weight.

Still missing compared with PixPin's free tier: automatic window/UI-element selection, numeric size and position entry, aspect-ratio locking, center-based resizing, pin click-through/thumbnail/hide-and-restore, text/file/color pins, QR recognition, capture history, printing, horizontal long screenshots, post-stitch editing and long-shot auto-scroll.
