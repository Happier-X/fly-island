## What's new

- **Fixed the launcher panel's oversized outer shadow.** A large CSS blur looked like a dark halo around the transparent window's margin. That outer shadow is removed while the thin border remains, bringing the panel closer to the other floating surfaces.
- Keeps v3.5.2's **configurable automatic updates**, along with the earlier double-tap Ctrl launcher trigger, quick launcher, and dual-monitor screenshot black-screen fix.

### Validation scope

- Frontend checks, browser regressions, Rust tests, and the Windows build passed; the launcher regression now checks the computed style to confirm there is no outer shadow and the border remains.
- The real download, automatic install, and restart flow for automatic updates was still not verified on a real desktop; see the v3.5.2 release notes.

## Downloads

Windows x64 EXE and MSI installers are available with their `.sig` files. `latest.json` is the in-app update manifest, and `SHA256SUMS.txt` lists the installer checksums.
